# Cyber Park — Windows desktop build

Bu repository Cyber Park hujjatlarni tekshirish ilovasi uchun Windows o‘rnatkichini yig‘adi.

**Maxfiy ma’lumotlar, API kalitlari va mijoz hujjatlarini GitHub’ga yuklamang.**

`Tekshiruv_API_tayyor/` papkasidagi ilova manba kodi va `.github/workflows/build-windows.yml` workflow to‘liq yuklangach, GitHub Actions `CyberPark_Tekshiruv_Setup.exe` yaratish uchun harakat qiladi. Windows sinovi muvaffaqiyatli bo‘lmaguncha installer tayyor deb hisoblanmaydi.
